## چه ساخته شد (مکانیزم‌ها — همه عمومی، بدون نام ریپو)

- `activator.rs` — فایل sidecar (`physarum_tube` / `utility:*`) فقط با سیگنال query (نام/stem در focus terms، یا سؤال usage/consumers) و فقط وقتی پروژه >۲۰ فایل (`FILL_GATE_MIN_FILES`؛ فیکسچرهای کوچک سیگنال دیگری ندارند — F21).
- `fold.rs::score` — `name_hits` با `focus_hits` (ident_tokens ∪ prompt_tokens).
- `seed/config_cohere.rs` — seedی که به نود Config یا فایل json/yaml/toml/ini/env رسیده حذف می‌شود اگر seed قوی در یک family کد باشد و prompt کلمه‌ی config/json/yaml/manifest/… نداشته باشد. `file:`/`path_hint:` معاف.
- `seed/weak_file_seed.rs` — seed ضعیف (concept/alias/token/…) که به نود **File** رسیده فقط با stem نام‌برده در prompt (جمع‌پذیر) می‌ماند؛ بدون seed قوی هیچ‌چیز حذف نمی‌شود.
- `style_routing::style_noise_penalty` — در سؤال استایل، فایل کامپوننت/اسکریپتی که prompt نام stem آن را نبرده ۲۸ penalty می‌گیرد؛ stylesheet هیچ‌وقت.
- `neuromesh_parser::tokenize_camel_chunk` — دنباله‌ی حروف بزرگ به کلمه‌ی mixed-case (یا پیشوند یک‌حرفی) می‌چسبد؛ `fold::tokenize_name` هم از آن استفاده می‌کند؛ workaround «کلمه‌ی چسبیده» از `twin_cohere` حذف شد.
- `skeleton.rs` — marker متد: `/* [neuromesh:fold:<id> | N lines] */` زیر خط header؛ ماژول: `| N lines | module L12-L40`.
- `tests/stage4_security.rs` — prompt خصمانه‌ی ۲ MB: ۷۱ توکن، ۱۱٫۳ s (debug)، هیچ فایلی خارج workspace؛ marker جعلی داخل فایل fold نمی‌شود.

- **جدید:** یک run در GitHub Actions بیش از یک ساعت `queued` ماند (runner نگرفت). با `gh run view <id> --json status` چک کن؛ اگر `queued` است، `gh workflow run ci.yml --ref <branch>` بزن و آن را cancel کن — کد مشکلی ندارد.
- **جدید:** PRی که روی برنچ stack شده باز شود و بعد `--base main` بگیرد، check های `pull_request` ندارد؛ `gh pr close N && gh pr reopen N` آن‌ها را راه می‌اندازد.
- probe: `NM_PROBE_NODES=1 NM_AUDIT_PATH=<abs path> NM_PROBE="<سؤال>" cargo test -p neuromesh-context --test artifact_audit packet_probe -- --ignored --nocapture` (مسیر باید absolute باشد).
